让插件作用于 Mac 播放的一切声音。

Curve 是一款免费的菜单栏应用，通过低延迟环回在 Mac 的所有音频上运行 Audio Unit 和 VST3 插件，无需安装驱动程序。内置 AutoEQ 耳机校正。

下载 Mac 版 工作原理

完全免费开源。需要 macOS 14.2 或更高版本，支持 Apple 芯片或 Intel。

耳机校正

在 AutoEQ 数据库中搜索你的耳机并选择结果，Curve 就会为你创建 Parametric EQ。你还可以从 AutoEQ、Squig.link 或 REW 导入曲线。

添加交叉馈送以获得更自然的立体声，或在耳机上模拟中场录音室音箱。

耳机 EQ 和 AutoEQ

让你的插件作用于一切

你已有的插件可以处理音乐、电影、通话以及 Mac 播放的任何其他声音。

为低延迟而生。 Curve 直接从音频设备的输出取音，路径中没有虚拟设备，缓冲区大小由你选择。

将每种设置存储为预设，然后通过菜单栏、全局快捷键或 MIDI 控制器切换。

环回和系统音频

乐器和音箱模拟

无需打开 DAW，就能随时使用钢琴、合成器或吉他效果链。Curve 在后台运行乐器插件，并将它们与系统音频混合。

使用 MIDI Learn 将插件参数、旁通和预设切换映射到你的控制器。

看见你听到的声音

将 Curve 的 Meter 连接到链路中的任意位置。它可显示电平和真峰值、指针 VU、LUFS 响度以及频谱。

开始使用

  1. 安装。 下载 Curve 并将其拷贝到“应用程序”文件夹。它已签名并经过公证，会以 显示在菜单栏中。
  2. 选择输出。 在 Audio Settings 中选择你的耳机、音箱或音频接口。
  3. 构建链路。 将插件添加到编辑器，并从 Interface Loopback 连接到 Audio Output。
  4. 存储预设。 它会出现在菜单中，随时可以切换。
