# 오디오 설정 및 기기

Settings > Audio Settings를 선택하여 오디오 및 MIDI 기기를 선택합니다.

## 인터페이스 및 채널 선택

출력 인터페이스를 선택하고, 프리셋에서 사용하는 경우 입력 인터페이스도 선택합니다. 그런 다음 원하는 채널을 활성화합니다. 채널은 Audio Input 및 Audio Output 노드에 녹색 핀으로 표시됩니다.

Curve의 [Interface Loopback (In) 노드](loopback.md)를 사용하는 경우에는 입력 인터페이스가 필요하지 않습니다.

## 샘플레이트 및 버퍼 크기

여기에서 샘플레이트와 버퍼 크기를 선택합니다. 버퍼가 작을수록 지연 시간은 줄어들지만 Mac의 부하가 커지고 소리가 끊길 수 있습니다.

**Always enforce sample rate**는 기본적으로 꺼져 있습니다. 꺼져 있으면 오디오 인터페이스나 다른 앱이 하드웨어의 샘플레이트를 변경할 때 Curve가 이에 맞춥니다. 켜져 있으면 Curve가 사용자가 선택한 샘플레이트로 강제로 되돌립니다.

## MIDI 기기

사용할 MIDI 입력과 출력을 활성화합니다. MIDI Input 또는 MIDI Output 노드를 사용하여 플러그인에 연결합니다. [MIDI 컨트롤](midi-control.md)에 사용하는 컨트롤러는 여기에서 활성화해야 합니다.

## 기기가 변경될 때

Curve는 일반적인 기기 변경을 자동으로 처리합니다.

- 선택한 인터페이스를 계속 사용합니다. 해당 인터페이스의 연결이 끊어지면 Mac 스피커와 같은 다른 출력으로 전환하지 않고 무음 상태가 됩니다.
- 인터페이스가 다시 연결되면 재연결하고 오디오를 복원합니다.
- Mac이 잠자기에서 깨어나면 오디오를 다시 시작합니다.

## AirPods 및 자동 전환

Curve가 오디오 인터페이스를 열어 두는 동안에는 macOS가 AirPods를 자동으로 전환하지 않을 수 있습니다. 전환을 허용하려면 Settings > Release audio interface when idle을 켭니다.

그러면 Curve는 5초간 무음이 지속된 후 인터페이스를 해제하고, 다른 앱이 사용을 시작하면 다시 엽니다. 이 동작은 Curve가 안정적으로 다시 깨어날 수 있는 경우에만 이루어지므로, 다음의 경우에는 인터페이스가 해제되지 않습니다.

- 입력이 별도 기기의 물리적 마이크 또는 라인 입력인 경우. BlackHole과 같은 가상 기기는 문제없습니다. 프리셋에서 Audio Input 노드가 연결되어 있으면 출력 인터페이스의 입력도 마찬가지입니다.
- 다른 앱이 해당 기기를 사용 중인 경우.
- Curve가 녹음 등의 작업을 수행 중인 경우.
