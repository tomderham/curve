# 설정 참고 자료

Curve 메뉴에서 Settings를 엽니다.

| 항목 | 기능 | 기본값 |
|---|---|---|
| Audio Settings | 오디오 및 MIDI 기기를 선택합니다. [오디오 설정 및 기기](audio-settings.md)를 참조하십시오. | |
| Plug-in Manager | 플러그인을 스캔하고 관리합니다. [Curve 시작하기](getting-started.md)를 참조하십시오. | |
| Force macOS System Audio to loopback | macOS의 시스템 출력을 Curve에서 선택한 인터페이스로 유지합니다. [루프백](loopback.md)을 참조하십시오. | 켬 |
| Prevent macOS from automatically sleeping | Curve의 오디오가 실행되는 동안 Mac이 잠자기 상태로 전환되지 않도록 합니다. | 끔 |
| Release audio interface when idle | 5초간 무음이 지속되면 인터페이스를 해제하여 AirPods 자동 전환을 허용합니다. [오디오 설정](audio-settings.md)을 참조하십시오. | 끔 |
| Check for Updates... | 지금 새 버전을 확인합니다. | |
| Auto-Check for App Updates | 새 버전을 자동으로 확인합니다. | 켬 |
| Open at Login | 로그인할 때 Curve를 시작합니다. | |
| Show in Dock | Dock과 Command-Tab 전환기에 Curve를 표시합니다. | 끔 |
| Global Menu Shortcut | 어디서나 Curve 메뉴를 여는 키 조합을 설정합니다. [키보드 단축키](keyboard-shortcuts.md)를 참조하십시오. | 끔 |
| MIDI Control | 컨트롤러를 사용한 프리셋 전환을 설정합니다. [MIDI 컨트롤](midi-control.md)을 참조하십시오. | |
| Curve Help | 이 가이드를 엽니다. | |
| About... | 버전 및 라이선스 정보를 표시합니다. | |
| Quit | Curve를 종료하고 오디오 처리를 중지합니다. | |
