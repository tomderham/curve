# 프리셋

프리셋은 그래프 전체를 저장합니다. 여기에는 플러그인과 그 설정, 연결, 오디오 채널 라우팅, MIDI 매핑이 포함됩니다. 프리셋을 전환하여 같은 플러그인의 설정을 바꾸거나, 다른 플러그인으로 교체하거나, 채널 라우팅을 변경할 수 있습니다.

## 프리셋 저장

1. Curve 메뉴에서 Save As Preset...를 선택합니다.
2. 이름을 입력하고 Save를 클릭합니다.

변경 사항은 자동으로 저장되지 않습니다. 유지하려면 Save As Preset...를 사용합니다.

## 기존 프리셋 변경

1. Curve 메뉴에서 프리셋을 선택하여 불러옵니다.
2. 변경합니다.
3. Save As Preset...를 선택하고 기존 이름을 고른 다음 대치할 것인지 확인합니다.

## 프리셋 전환

프리셋은 Curve 메뉴에 알파벳순으로 표시되며 현재 프리셋에는 체크 표시가 있습니다. 하나를 선택하면 즉시 전환됩니다. Curve는 먼저 묻지 않으므로, 유지하려는 변경 사항은 전환하기 전에 저장하십시오.

[키보드](keyboard-shortcuts.md)나 [MIDI 컨트롤러](midi-control.md)로도 프리셋을 전환할 수 있습니다. 프리셋 파일을 직접 불러오려면 편집기 창으로 드래그합니다.

## 새 프리셋 시작

빈 그래프에서 다시 시작하려면 편집기 창 왼쪽 상단의 메뉴 아이콘을 클릭하고 New Preset을 선택합니다. Audio Input, Interface Loopback (In), Audio Output을 제외한 모든 노드가 제거됩니다. 이 노드들은 연결되어 있지 않으므로 연결하기 전까지는 소리가 나지 않습니다.

그래프에 이 노드들만 있는 경우가 아니면 Curve가 먼저 묻습니다. 플러그인 창에서 변경한 설정은 변경 사항으로 추적되지 않기 때문입니다. 현재 구성을 유지하려면 Save As Preset...를, 버리려면 Discard and Start New를 선택합니다.

## 장면

여러 프리셋이 바이패스한 노드나 다르게 설정한 플러그인처럼 몇 가지 설정만 다르다면 장면으로 만들 수 있습니다. 장면은 플러그인과 연결을 공유하므로 한 번만 변경하면 모두 업데이트됩니다. 각 장면은 다른 프리셋처럼 Curve의 메뉴에 표시되며 같은 방법으로 전환합니다. Save Preset 창에서는 서로 공유하는 장면이 같은 색으로 표시되고, 하나를 선택하면 나머지가 강조 표시됩니다.

각 장면이 따로 가지는 것:

- 각 노드의 바이패스 여부.
- Vary by Scene로 설정한 노드의 설정. 노드를 오른쪽 클릭하고 Vary by Scene를 선택하면 겹친 카드 모양의 작은 배지가 표시됩니다.

나머지는 모두 공유됩니다. 다른 노드와 그 설정, 연결, 채널 라우팅, MIDI 매핑입니다. 어느 장면에서든 공유 노드를 변경하고 저장하면 모든 장면에 반영됩니다. Vary by Scene로 설정한 노드도 채널과 연결은 공유됩니다.

장면을 만들려면:

1. 새 장면의 시작점이 될 프리셋을 불러옵니다.
2. 새 장면에서 다르게 설정할 각 플러그인을 오른쪽 클릭하고 Vary by Scene를 선택합니다.
3. 새 장면에 맞게 변경합니다.
4. Save As Preset...를 선택하고 새 이름을 입력한 다음 장면 옵션을 선택하고 Save를 클릭합니다.

저장하기 전에 Save Preset 창에 저장으로 업데이트되는 다른 장면과, 그 장면에서 설정이 바뀌는 공유 노드가 표시됩니다. 이 장면에만 적용할 설정이라면 취소하고 해당 노드를 Vary by Scene로 설정한 다음 다시 저장하십시오.

장면을 변경하려면 불러와서 변경한 다음 같은 이름으로 저장합니다. 공유하는 다른 장면에 덮어써 저장하면 그 장면이 대체되며, 장면으로 유지됩니다. 추가한 노드는 다른 장면에도 바이패스된 상태로 나타나므로, 그 장면에서 켜기 전까지는 소리가 같습니다.

장면이 다른 장면과 공유하지 않게 하려면 Save Preset 창에서 장면을 오른쪽 클릭하고 Convert to Standalone Preset를 선택합니다. 현재 설정은 그대로 유지됩니다.

## 프리셋 이름 변경 또는 삭제

Save Preset 창에서 프리셋을 오른쪽 클릭하여 이름을 변경하거나, 휴지통으로 이동하거나, Finder에서 볼 수 있습니다.

프리셋은 `~/Library/Application Support/Curve/Presets/`에 있는 `.filtergraph` 파일이므로 Finder에서도 관리할 수 있습니다.
