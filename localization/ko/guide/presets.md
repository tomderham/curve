# 프리셋

프리셋은 그래프 전체를 저장합니다. 여기에는 플러그인과 그 설정, 연결, 오디오 채널 라우팅, MIDI 매핑이 포함됩니다. 프리셋을 전환하여 같은 플러그인의 설정을 바꾸거나, 다른 플러그인으로 교체하거나, 채널 라우팅을 변경할 수 있습니다.

## 프리셋 저장

1. Curve 메뉴에서 Save As Preset...를 선택합니다.
2. 이름을 입력하고 Save를 클릭합니다.

변경 사항은 자동으로 저장되지 않습니다. 유지하려면 Save As Preset...를 사용합니다.

## 기존 프리셋 변경

1. Curve 메뉴에서 프리셋을 선택하여 불러옵니다.
2. 변경합니다.
3. Save As Preset...를 선택하고 기존 이름을 고른 다음 대치할 것인지 확인합니다.

## 프리셋 전환

프리셋은 Curve 메뉴에 알파벳순으로 표시되며 현재 프리셋에는 체크 표시가 있습니다. 하나를 선택하면 즉시 전환됩니다.

[키보드](keyboard-shortcuts.md)나 [MIDI 컨트롤러](midi-control.md)로도 프리셋을 전환할 수 있습니다. 프리셋 파일을 직접 불러오려면 편집기 창으로 드래그합니다.

## 프리셋 이름 변경 또는 삭제

Save Preset 창에서 프리셋을 오른쪽 클릭하여 이름을 변경하거나, 휴지통으로 이동하거나, Finder에서 볼 수 있습니다.

프리셋은 `~/Library/Application Support/Curve/Presets/`에 있는 `.filtergraph` 파일이므로 Finder에서도 관리할 수 있습니다.
