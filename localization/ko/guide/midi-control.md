# MIDI 컨트롤

MIDI 컨트롤러나 키보드로 악기 플러그인을 연주하고, 플러그인 파라미터를 변경하고, 노드를 바이패스하거나 뮤트하고, 프리셋을 전환할 수 있습니다. [Audio Settings](audio-settings.md)의 MIDI 입력에서 활성화하십시오.

## 플러그인 제어 방법 선택

컨트롤러로 플러그인을 제어하는 방법은 두 가지입니다.

- **MIDI를 플러그인에 연결합니다.** MIDI Input 노드가 MIDI를 플러그인의 호박색 입력 핀으로 직접 보내고, 처리 방법은 플러그인이 결정합니다. 악기를 연주하거나 플러그인에 내장된 MIDI 매핑을 사용할 때 이 방법을 사용하십시오.
- **Curve의 MIDI Learn을 사용합니다.** Curve가 컨트롤러를 직접 읽은 다음 플러그인의 파라미터, 바이패스, 뮤트를 대신 변경합니다. MIDI Input 노드나 연결이 필요하지 않습니다. 호박색 입력 핀이 없는 플러그인과 바이패스, 뮤트에 이 방법을 사용하십시오.

MIDI Learn은 플러그인이 호스트에 제공하는 파라미터만 제어할 수 있습니다. 일부 플러그인, 특히 대형 악기는 컨트롤의 일부만 제공합니다. MIDI Learn 중에 플러그인 창에서 컨트롤을 움직여도 아무 반응이 없으면 Curve는 해당 컨트롤을 매핑할 수 없습니다.

플러그인에 호박색 입력 핀과 자체 MIDI Learn 기능이 있다면 대개 모든 컨트롤을 제어할 수 있으므로 그쪽이 더 쉬운 경우가 많습니다. MIDI Input 노드를 플러그인에 연결한 다음 플러그인 창에서 매핑을 설정하십시오. 자세한 방법은 플러그인 설명서를 참조하십시오.

노브나 버튼마다 한 가지 방법만 사용하십시오. Curve의 MIDI Learn으로 매핑한 컨트롤은 MIDI Input 노드를 통해 플러그인에 전달되지 않으므로 플러그인이 반응하지 않습니다.

## 악기 플러그인 연주

1. 편집기 배경을 오른쪽 클릭하고 악기 플러그인을 추가합니다.
2. 편집기 배경을 오른쪽 클릭하고 MIDI I/O > MIDI Input을 선택합니다.
3. MIDI Input 노드의 호박색 핀에서 악기 상단의 호박색 핀으로 드래그합니다. MIDI 핀과 연결은 호박색이고, 오디오 핀과 연결은 회색입니다.
4. 악기의 회색 출력 핀에서 Audio Output 노드로 드래그합니다.
5. 설정을 유지하려면 Save As Preset...를 선택합니다.

MIDI에 반응하는 이펙트 플러그인도 같은 방식으로 연결합니다. 플러그인에서 외부 기기로 MIDI를 보내려면 Audio Settings에서 해당 기기를 MIDI 출력으로 활성화한 다음, 플러그인의 호박색 출력 핀을 MIDI Output 노드에 연결합니다.

## MIDI Learn으로 컨트롤 매핑

1. 편집기 왼쪽 위의 메뉴 아이콘을 클릭하고 MIDI Learn을 선택합니다. 편집기에 강조 테두리가 표시되고 상태 막대에 안내가 나타납니다.
2. 제어할 대상을 선택합니다.
   - 플러그인 파라미터의 경우 플러그인 창을 열고 컨트롤을 움직입니다.
   - 노드 바이패스의 경우 해당 전원 버튼을 클릭합니다.
   - 노드를 뮤트하려면 노드를 오른쪽 클릭하고 Mute를 선택합니다.
   - 템포, Tap 또는 Start/Stop의 경우 편집기 오른쪽 위에서 해당 항목을 클릭합니다.
3. 컨트롤러의 노브, 페이더 또는 버튼을 움직입니다. 매핑이 즉시 이루어지며, 계속해서 다른 컨트롤을 매핑할 수 있습니다.
4. 끝내려면 Esc를 누르거나 MIDI Learn을 다시 선택합니다.

매핑은 프리셋과 함께 저장되므로, 유지하려면 Save As Preset...를 사용합니다.

## 매핑 제거

- 선택한 파라미터, 바이패스, 뮤트의 매핑을 제거하려면 MIDI Learn 중에 Delete를 누릅니다.
- 노드의 모든 매핑을 제거하려면 노드를 오른쪽 클릭하고 Clear MIDI Mappings를 선택합니다.
- 컨트롤을 다른 대상으로 옮기려면 이전 매핑을 제거하십시오. 다시 매핑하면 대상이 추가되기 때문입니다.

## 매핑된 컨트롤의 동작

- 노브와 페이더(CC)는 파라미터의 전체 범위를 사용합니다. MIDI Mappings for Current Preset...에서 범위를 좁힐 수 있습니다(아래 참조).
- 노트와 프로그램 체인지는 대상을 전환합니다.
- 바이패스와 뮤트, 그리고 Record 같은 켜기/끄기 파라미터의 경우 Curve는 CC 버튼이 누를 때마다 전환하는 모멘터리 방식인지, 버튼 상태를 따르는 래칭 방식인지 판단합니다.
- 하나의 컨트롤로 여러 대상을 제어할 수 있습니다. 대상을 추가하려면 MIDI Learn으로 다시 매핑합니다. 대상이 여러 개인 컨트롤은 뮤트된 노드의 파라미터를 바꾸지 않으므로, [장면](presets.md)에서 노브 하나로 각 장면이 사용하는 악기를 제어할 수 있습니다.
- 템포에 매핑한 노브나 페이더는 40~240 BPM 범위를 움직이며, MIDI Mappings for Current Preset...에서 범위를 좁힐 수 있습니다. Tap에 매핑한 버튼은 템포를 탭하고, Start/Stop에 매핑한 버튼은 트랜스포트를 시작하고 정지합니다.

매핑이 있는 노드에는 작은 MIDI 소켓 아이콘이 표시됩니다. 노드 위에 포인터를 올리면 상태 막대에서 매핑을 볼 수 있습니다.

매핑된 MIDI 메시지는 MIDI Input 노드를 통해 플러그인으로 전달되지 않습니다. 그 외의 MIDI는 모두 전달됩니다.

## 매핑 조정

편집기 창 왼쪽 상단의 메뉴 아이콘을 클릭하고 MIDI Mappings for Current Preset...를 선택하면 불러온 프리셋의 매핑을 볼 수 있습니다. MIDI Learn을 사용하거나 프리셋을 전환하는 동안에도 창을 열어 둘 수 있습니다. 매핑마다 다음을 설정할 수 있습니다:

- **Mode:** 노브나 페이더로 값을 설정하는 Range, 누를 때마다 두 값 사이를 전환하는 Toggle, 또는 버튼을 따라 누르고 있거나 잠겨 있는 동안 켜지는 Follow입니다.
- **From 및 To:** 노브나 페이더가 움직이는 값의 범위입니다. 범위를 좁히면 단계가 더 세밀해집니다. 예를 들어 Gain 노드에서 -20 dB에서 +6 dB로 설정합니다. Toggle과 Follow에서는 끄기와 켜기 값입니다. 파라미터의 단위로 값을 입력하거나 25%와 같은 백분율을 입력하십시오.
- **Invert:** 컨트롤을 반대로 바꿉니다.

바이패스와 뮤트 매핑에는 From과 To가 없습니다. 매핑을 제거하려면 ×를 클릭하십시오. 매핑은 프리셋과 함께 저장되므로 변경 내용을 유지하려면 Save As Preset...을 사용하십시오.

## 컨트롤러로 프리셋 전환

Settings > Preferences...를 선택하고 MIDI 탭을 엽니다. 이 설정은 모든 프리셋에 적용됩니다.

- **Program Change Selects Preset:** 기본적으로 꺼져 있습니다. 프로그램 체인지 0은 메뉴의 첫 번째 프리셋을, 1은 두 번째 프리셋을 불러오며, [숫자 키 단축키](keyboard-shortcuts.md)와 같은 순서를 따릅니다.
- **Next Preset Control** 및 **Previous Preset Control:** 하나 옆의 MIDI Learn...를 클릭한 다음 사용할 컨트롤러 버튼을 누릅니다.
- **Clear Preset Controls:** 이 두 버튼 할당을 제거합니다.

불러온 프리셋이 같은 컨트롤을 직접 매핑하면 프리셋의 매핑이 대신 사용됩니다. Save As Preset...나 Audio Settings 같은 창이 열려 있는 동안에는 MIDI로 프리셋이 바뀌지 않습니다.

## Curve 자체 플러그인의 컨트롤

| 플러그인 | 컨트롤 |
|---|---|
| Gain | 게인 및 음소거 |
| Pan | 팬 |
| Clipper | 실링 |
| Stereo Utility | 모드 및 폭 |
| Headphone Crossfeed | 양 |
| Audio Recorder | 녹음 시작 및 중지 |

Headphone Speaker Emulation, Invert Phase, Mid/Side Encoder, Mid/Side Decoder에는 설정이 없으므로 대신 바이패스를 매핑하십시오. Delay는 매핑할 수 없습니다.
