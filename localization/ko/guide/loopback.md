# 루프백 및 시스템 오디오

루프백을 사용하면 macOS의 오디오가 헤드폰이나 스피커에 도달하기 전에 Curve를 거치도록 보낼 수 있습니다. 이렇게 하면 Mac에서 재생되는 모든 소리에 EQ를 적용할 수 있습니다.

## Curve의 Interface Loopback 노드 사용

추가 소프트웨어나 드라이버가 필요하지 않습니다.

1. [Audio Settings](audio-settings.md)에서 오디오를 들을 출력 인터페이스를 선택합니다.
2. 프리셋에서 Audio Input 대신 Interface Loopback (In) 노드를 입력으로 사용합니다.
3. 플러그인을 거쳐 Audio Output 노드에 연결합니다.

이 노드는 원래 출력 인터페이스로 바로 전달되었을 오디오를 비트 퍼펙트로 받습니다. 노드가 없으면 편집기의 오른쪽 클릭 메뉴에 있는 Audio I/O에서 추가합니다.

## 모든 시스템 오디오를 Curve로 보내기

Settings 메뉴의 **Force macOS System Audio to loopback**은 기본적으로 켜져 있습니다. 이 옵션은 macOS의 시스템 출력을 Curve에서 선택한 인터페이스로 유지합니다. 시스템 출력을 직접 선택하려면 끄십시오.

## 오디오 인터페이스의 자체 루프백 사용

인터페이스에 하드웨어 루프백이 있다면 지연 시간을 최소화할 수 있으므로 좋은 대안이 될 수 있습니다. 예를 들어 RME TotalMix의 경우 다음과 같습니다.

1. TotalMix의 Loopback 기능을 사용하여 출력 채널 쌍을 비어 있는 입력 채널 쌍으로 보냅니다.
2. Curve에서 해당 입력 채널을 선택하고 Audio Input 노드를 사용합니다.
3. 소프트웨어 재생 채널 중 일부를 Curve의 출력으로 선택합니다.
4. TotalMix에서 해당 재생 채널을 하드웨어 출력에 할당합니다.

이 구성에서는 Interface Loopback (In) 노드를 사용하지 마십시오.

## 중요: 사용하지 않는 루프백 핀

Interface Loopback (In) 노드가 연결되어 있으면 해당 채널의 직접 오디오가 더 이상 출력 기기에 도달하지 않습니다. 사용하지 않는 프리셋에 이 노드가 있으면 제거하거나 핀을 연결하지 않은 상태로 두십시오. 그렇지 않으면 예기치 않게 음소거될 수 있습니다.

## 리디렉션 작동 방식

노드의 핀이 연결되면 선택한 출력 인터페이스의 기본 스트림인 Stream 0의 채널이 노드로 리디렉션됩니다. 인터페이스 드라이버가 다른 스트림에 할당한 채널은 영향을 받지 않습니다.
