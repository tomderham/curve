# ループバックとシステムオーディオ

ループバックを使うと、macOSのオーディオがヘッドフォンやスピーカーに届く前にCurveを通すことができます。これにより、Macで再生するすべての音にEQをかけられます。

## CurveのInterface Loopbackノードを使用する

追加のソフトウェアやドライバは必要ありません。

1. [Audio Settings](audio-settings.md)で、オーディオを聴く出力インターフェイスを選択します。
2. プリセットで、Audio Inputの代わりにInterface Loopback (In)ノードを入力として使用します。
3. プラグインを経由してAudio Outputノードに接続します。

このノードは、本来出力インターフェイスへ直接送られるはずのオーディオをビットパーフェクトで受け取ります。ノードがない場合は、エディタの右クリックメニューのAudio I/Oから追加します。

## すべてのシステムオーディオをCurveに送る

Settingsメニューの**Force macOS System Audio to loopback**は、デフォルトでオンです。これにより、macOSのシステム出力がCurveで選択したインターフェイスに保たれます。システム出力を自分で選びたい場合はオフにします。

## オーディオインターフェイスのループバックを使用する

インターフェイスにハードウェアループバックがある場合は、レイテンシを最小限に抑えられるため、こちらも良い選択肢です。たとえばRME TotalMixの場合は次のようにします。

1. TotalMixのLoopback機能を使って、出力チャンネルのペアを空いている入力チャンネルのペアに送ります。
2. Curveでそれらの入力チャンネルを選択し、Audio Inputノードを使用します。
3. ソフトウェア再生チャンネルのいくつかをCurveの出力として選択します。
4. TotalMixで、それらの再生チャンネルをハードウェア出力に割り当てます。

この構成では、Interface Loopback (In)ノードを使用しないでください。

## 重要: 未使用のループバックピン

Interface Loopback (In)ノードが接続されていると、該当チャンネルの直接のオーディオは出力デバイスに届かなくなります。使用していないプリセットにこのノードが含まれている場合は、削除するかピンを未接続のままにしてください。そうしないと、予期せずミュートされることがあります。

## リダイレクトの仕組み

ノードのピンが接続されると、選択した出力インターフェイスのプライマリストリームであるStream 0のチャンネルがノードにリダイレクトされます。インターフェイスのドライバが別のストリームに割り当てたチャンネルには影響しません。
