# オーディオ設定とデバイス

Settings > Audio Settingsを選択して、オーディオデバイスとMIDIデバイスを選びます。

## インターフェイスとチャンネルを選ぶ

出力インターフェイスを選択し、プリセットで使用する場合は入力インターフェイスも選択します。次に、使用するチャンネルを有効にします。チャンネルは、Audio InputノードとAudio Outputノードに灰色のピンとして表示されます。

Curveの[Interface Loopback (In)ノード](loopback.md)を使用する場合、入力インターフェイスは必要ありません。

Curveは出力インターフェイスごとにサンプルレート、バッファサイズ、有効な出力チャンネルを記憶し、そのインターフェイスに戻したときに復元します。

## macOSの出力に従う

**Use output interface selected in macOS**をオンにすると、Curveの出力をmacOSで選べるようになります。システム設定、コントロールセンター、またはメニューバーで出力を選ぶと、Curveは約1秒でその出力に処理を移します。そのインターフェイスが取り外されると、CurveはmacOSが次に使う出力に移ります。オンの間、CurveのOutputメニューは灰色で表示されます。

新しいインターフェイスにない出力へのプリセットの接続は保持されますが、その出力を持つインターフェイスに戻すまで無音になります。特定のヘッドフォン用のEQなど、1つのインターフェイス向けの補正は、macOSが切り替えたどの出力にも適用されます。

オンの間は、**Default Presets for each output interface...**を選択すると、インターフェイスごとにプリセットを選べます。macOSがインターフェイスを切り替えると、Curveはそのデフォルトのプリセットを読み込みます。Noneに設定したインターフェイスでは、読み込まれているプリセットがそのまま使われます。**Also load at launch**をオンにすると、Curveの起動時に、最後に使ったプリセットではなく、macOSが使用しているインターフェイスのデフォルトのプリセットを読み込みます。デフォルトのプリセットが見つからない場合、Curveは現在のプリセットを使い続け、エディタのステータスバーにその旨を表示します。

## macOSをCurveのインターフェイスに保つ

**Force macOS system output to this interface**は、デフォルトでオンです。macOSのシステム出力をCurveの出力インターフェイスに保つため、[Interface Loopback (In)ノード](loopback.md)がすべてのシステムオーディオを受け取れます。システム出力を自分で選びたい場合はオフにします。Use output interface selected in macOSがオンの間は、macOSの出力が常にCurveの出力になるため、灰色で表示されます。

## サンプルレートとバッファサイズ

ここでサンプルレートとバッファサイズを選択します。バッファを小さくするとレイテンシは下がりますが、Macへの負荷が増え、音切れの原因になることがあります。

**Always enforce sample rate**は、デフォルトではオフです。オフの場合、オーディオインターフェイスや他のアプリがハードウェアのサンプルレートを変更すると、Curveはそれに合わせます。オンの場合、Curveは選択したレートに強制的に戻します。

## MIDIデバイス

使用するMIDI入力とMIDI出力を有効にします。MIDI InputノードまたはMIDI Outputノードを使って、プラグインに接続します。[MIDIコントロール](midi-control.md)に使用するコントローラは、ここで有効にしておく必要があります。

## デバイスが変わったとき

Curveは、よくあるデバイスの変更に自動で対応します。

- Use output interface selected in macOSがオンでない限り、選択したインターフェイスを使い続けます。そのインターフェイスが取り外されると、Curveはその他の出力(Macのスピーカーなど)に切り替えず、無音になります。
- インターフェイスが戻ると、再接続してオーディオを復元します。
- Macがスリープから復帰すると、オーディオを再開します。

## AirPodsと自動切り替え

Curveがオーディオインターフェイスを開いている間、macOSはAirPodsを自動で切り替えないことがあります。切り替えを許可するには、Settings > Release audio interface when idleをオンにします。

オンにすると、Curveは5秒間の無音の後にインターフェイスを解放し、他のアプリが使い始めると再び開きます。これはCurveが確実に再開できる場合にのみ行われるため、次の場合はインターフェイスは解放されません。

- 入力が、別のデバイスの物理マイクまたはライン入力である場合。BlackHoleなどの仮想デバイスは問題ありません。プリセットでAudio Inputノードが接続されている場合は、出力インターフェイスの入力も同様です。
- 他のアプリがそのデバイスを使用している場合。
- Curveが録音中などで処理を実行している場合。
