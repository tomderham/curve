# Curve Help

このヘルプは機械翻訳です。修正は[GitHub](https://github.com/tomderham/curve/issues)で受け付けています。

Curveは、macOS用の無料で軽量なオーディオプラグインホストです。メニューバーに常駐し、Audio UnitとVST3プラグインのチェーンをバックグラウンドで動かし続けます。これにより、Macのオーディオ全体にEQやヘッドフォン処理などのエフェクトをかけ、設定を瞬時に切り替えることができます。

## はじめに

- [Curveを使い始める](getting-started.md): Curveのインストール、プラグインのスキャン、最初のプリセットの作成。
- [プリセット](presets.md): プリセットの保存、読み込み、切り替え、名前変更、削除。
- [エディタ](editor.md): ノードの追加、接続、バイパス、プラグインウインドウの表示。

- [ループバックとシステムオーディオ](loopback.md): macOSや他のアプリのオーディオをCurveで処理する方法。
