# プリセット

プリセットには、グラフ全体が保存されます。これにはプラグインとその設定、接続、オーディオチャンネルのルーティング、MIDIマッピングが含まれます。プリセットを切り替えることで、同じプラグインの設定を変更したり、別のプラグインに替えたり、チャンネルのルーティングを変更したりできます。

## プリセットを保存する

1. CurveのメニューからSave As Preset...を選択します。
2. 名前を入力してSaveをクリックします。

変更は自動では保存されません。変更を保持したいときはSave As Preset...を使用します。

## 既存のプリセットを変更する

1. Curveのメニューでプリセットを選択して読み込みます。
2. 変更を加えます。
3. Save As Preset...を選択し、既存の名前を選んで、置き換えることを確認します。

## プリセットを切り替える

プリセットはCurveのメニューにアルファベット順で表示され、現在のプリセットにはチェックマークが付きます。選択するとすぐに切り替わります。Curveは確認しないので、残したい変更は切り替える前に保存してください。

[キーボード](keyboard-shortcuts.md)や[MIDIコントローラ](midi-control.md)からプリセットを切り替えることもできます。プリセットファイルを直接読み込むには、エディタウインドウにドラッグします。

## 新しいプリセットを始める

空のグラフからやり直すには、エディタウインドウの左上にあるメニューアイコンをクリックしてNew Presetを選択します。Audio Input、Interface Loopback (In)、Audio Outputを除くすべてのノードが削除されます。これらは接続されていないため、接続するまで音は出ません。

グラフにこれらのノードしかない場合を除き、Curveは先に確認します。プラグインのウインドウで変更した設定は、変更として記録されないためです。現在の構成を残すにはSave As Preset...を、破棄するにはDiscard and Start Newを選択します。

## プリセットの名前を変更または削除する

Save Presetウインドウでプリセットを右クリックすると、名前の変更、ゴミ箱への移動、Finderでの表示ができます。

プリセットは`~/Library/Application Support/Curve/Presets/`にある`.filtergraph`ファイルなので、Finderで管理することもできます。
