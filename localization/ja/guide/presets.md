# プリセット

プリセットには、グラフ全体が保存されます。これにはプラグインとその設定、接続、オーディオチャンネルのルーティング、MIDIマッピングが含まれます。プリセットを切り替えることで、同じプラグインの設定を変更したり、別のプラグインに替えたり、チャンネルのルーティングを変更したりできます。

## プリセットを保存する

1. CurveのメニューからSave As Preset...を選択します。
2. 名前を入力してSaveをクリックします。

変更は自動では保存されません。変更を保持したいときはSave As Preset...を使用します。

## 既存のプリセットを変更する

1. Curveのメニューでプリセットを選択して読み込みます。
2. 変更を加えます。
3. Save As Preset...を選択し、既存の名前を選んで、置き換えることを確認します。

## プリセットを切り替える

プリセットはCurveのメニューにアルファベット順で表示され、現在のプリセットにはチェックマークが付きます。選択するとすぐに切り替わります。Curveは確認しないので、残したい変更は切り替える前に保存してください。

[キーボード](keyboard-shortcuts.md)や[MIDIコントローラ](midi-control.md)からプリセットを切り替えることもできます。プリセットファイルを直接読み込むには、エディタウインドウにドラッグします。

## 新しいプリセットを始める

空のグラフからやり直すには、エディタウインドウの左上にあるメニューアイコンをクリックしてNew Presetを選択します。Audio Input、Interface Loopback (In)、Audio Outputを除くすべてのノードが削除されます。これらは接続されていないため、接続するまで音は出ません。

グラフにこれらのノードしかない場合を除き、Curveは先に確認します。プラグインのウインドウで変更した設定は、変更として記録されないためです。現在の構成を残すにはSave As Preset...を、破棄するにはDiscard and Start Newを選択します。

## シーン

いくつかの設定(バイパスしたノードや、設定の異なるプラグインなど)だけが違う複数のプリセットは、シーンにできます。シーンはプラグインと接続を共有するため、変更は1回行うだけですべてに反映されます。各シーンはほかのプリセットと同じようにCurveのメニューに表示され、同じ方法で切り替えます。Save Presetウインドウでは、互いに共有しているシーンが同じ色で表示され、1つを選択するとほかのシーンが強調表示されます。

各シーンが個別に持つもの:

- 各ノードをバイパスしているかどうか。
- Vary by Sceneに設定したノードの設定。ノードを右クリックしてVary by Sceneを選択すると、重なったカードの小さなバッジが表示されます。

それ以外はすべて共有されます。ほかのノードとその設定、接続、チャンネルのルーティング、MIDIの割り当てです。どのシーンでも共有ノードを変更して保存すると、すべてのシーンに反映されます。Vary by Sceneに設定したノードでも、チャンネルと接続は共有されます。

シーンを作るには:

1. 新しいシーンの元にするプリセットを読み込みます。
2. 新しいシーンで設定を変えるプラグインをそれぞれ右クリックし、Vary by Sceneを選択します。
3. 新しいシーン用に変更します。
4. Save As Preset...を選択し、新しい名前を入力してシーンのオプションを選び、Saveをクリックします。

保存する前に、Save Presetウインドウには、保存によって更新されるほかのシーンと、それらのシーンで設定が変わる共有ノードが表示されます。その設定をこのシーンだけのものにしたい場合は、キャンセルしてそのノードをVary by Sceneに設定し、もう一度保存します。

シーンを変更するには、読み込んで変更し、同じ名前で保存します。共有しているほかのシーンに上書き保存すると、そのシーンが置き換えられ、シーンのまま残ります。追加したノードはほかのシーンにもバイパスされた状態で表示されるため、そこでオンにするまで音は変わりません。

シーンをほかのシーンと共有しないようにするには、Save Presetウインドウでそのシーンを右クリックし、Convert to Standalone Presetを選択します。現在の設定はそのまま残ります。

## プリセットの名前を変更または削除する

Save Presetウインドウでプリセットを右クリックすると、名前の変更、ゴミ箱への移動、Finderでの表示ができます。

プリセットは`~/Library/Application Support/Curve/Presets/`にある`.filtergraph`ファイルなので、Finderで管理することもできます。
