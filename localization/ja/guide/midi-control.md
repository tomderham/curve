# MIDIコントロール

MIDIコントローラやキーボードを使って、インストゥルメントプラグインの演奏、プラグインパラメータの変更、ノードのバイパス、プリセットの切り替えができます。[Audio Settings](audio-settings.md)のMIDI入力で有効にしてください。

インストゥルメントの演奏や、他のプラグインへのMIDI送信には、そのプラグインに接続されたMIDI Inputノードが必要です。MIDI Learnによるパラメータ、バイパス、プリセットの操作には、MIDI Inputノードもプリセット内の接続も必要ありません。

## インストゥルメントプラグインを演奏する

1. エディタの背景を右クリックし、インストゥルメントプラグインを追加します。
2. エディタの背景を右クリックし、MIDI I/O > MIDI Inputを選択します。
3. MIDI Inputノードの赤いピンから、インストゥルメントの上部にある赤いピンへドラッグします。MIDIのピンと接続は赤色、オーディオのピンと接続は緑色です。
4. インストゥルメントの緑色の出力ピンから、Audio Outputノードへドラッグします。
5. 設定を保持するには、Save As Preset...を選択します。

MIDIに反応するエフェクトプラグインも同じ方法で接続します。プラグインから外部デバイスにMIDIを送るには、Audio SettingsでそのデバイスをMIDI出力として有効にし、プラグインの赤い出力ピンをMIDI Outputノードに接続します。

## MIDI Learnでコントロールを割り当てる

1. 任意のノードを右クリックしてMIDI Learnを選択します。エディタの枠が強調表示され、ステータスバーに案内が表示されます。
2. 操作する対象を選びます。
   - プラグインパラメータの場合は、プラグインのウインドウを開いてコントロールを動かします。
   - ノードのバイパスの場合は、その電源ボタンをクリックします。
3. コントローラのノブ、フェーダー、ボタンを動かします。すぐにマッピングされ、続けて他のコントロールも割り当てられます。
4. 終了するには、Escを押すか、もう一度MIDI Learnを選択します。

マッピングはプリセットとともに保存されるため、保持するにはSave As Preset...を使用します。

## マッピングを削除する

- 選択したパラメータまたはバイパスのマッピングを削除するには、MIDI Learn中にDeleteを押します。
- ノードのマッピングをすべて削除するには、ノードを右クリックしてClear MIDI Mappingsを選択します。

## マッピングしたコントロールの動作

- ノブとフェーダー(CC)は、パラメータの全範囲をカバーします。
- ノートとプログラムチェンジは、対象を切り替えます。
- バイパスの場合、CurveはCCボタンがモーメンタリ(押すたびにバイパスを切り替え)かラッチ(バイパスがボタンの状態に従う)かを判断します。

マッピングがあるノードには、小さなMIDIソケットのアイコンが表示されます。ノードの上にポインタを置くと、ステータスバーにマッピングが表示されます。

マッピングされたMIDIメッセージは、MIDI Inputノードを通じてプラグインに渡されません。その他のMIDIはすべて渡されます。

## コントローラからプリセットを切り替える

Settings > MIDI Controlを開きます。これらの設定はすべてのプリセットに適用されます。

- **Program Change Selects Preset:** デフォルトではオフです。プログラムチェンジ0でメニューの最初のプリセット、1で2番目のプリセットというように、[数字キーのショートカット](keyboard-shortcuts.md)と同じ順序で読み込みます。
- **Next Preset Control**と**Previous Preset Control:** どちらかを選択し、使用するコントローラのボタンを押します。
- **Clear Preset Controls:** これら2つのボタン割り当てを削除します。

## Curve独自のプラグインのコントロール

| プラグイン | コントロール |
|---|---|
| Gain | ゲインとミュート |
| Pan | パン |
| Clipper | シーリング |
| Stereo Utility | モードと幅 |
| Headphone Crossfeed | 量 |
| Audio Recorder | 録音の開始と停止 |

Headphone Speaker Emulation、Invert Phase、Mid/Side Encoder、Mid/Side Decoderには設定がないため、代わりにバイパスをマッピングしてください。Delayはマッピングできません。
