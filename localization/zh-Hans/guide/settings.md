# 设置参考

从 Curve 菜单中打开 Settings。

| 项目 | 功能 |
|---|---|
| Audio Settings | 选择音频和 MIDI 设备。请参阅[音频设置和设备](audio-settings.md)。 |
| Plug-in Manager | 扫描和管理插件。请参阅[入门指南](getting-started.md)。 |
| Preferences... | 打开 Preferences 窗口，见下文。 |
| Curve Help | 打开本指南。 |
| About... | 显示版本和许可详情。 |
| Quit | 退出 Curve 并停止其音频处理。 |

## Preferences

Preferences 窗口有三个标签页。使用 Curve 时它可以保持打开。

### General

| 项目 | 功能 | 默认值 |
|---|---|---|
| Open at Login | 在你登录时启动 Curve。 | |
| Show in Dock | 在程序坞和 Command-Tab 切换器中显示 Curve。 | 关闭 |
| Prevent macOS from automatically sleeping | 在 Curve 的音频运行时阻止 Mac 进入空闲睡眠。 | 关闭 |
| Release audio interface when idle | 静音 5 秒后释放接口，以便 AirPods 自动切换。请参阅[音频设置](audio-settings.md)。 | 关闭 |
| Auto-Check for App Updates | 自动检查新版本。 | 打开 |
| Check for Updates... | 立即检查新版本。 | |

### Keyboard

| 项目 | 功能 | 默认值 |
|---|---|---|
| Volume Keys | 让键盘的音量键调节 Curve 的输出音量，或仅调节 Interface Loopback (In) 的音量，适用于自身没有音量控制的接口。请参阅[键盘快捷键](keyboard-shortcuts.md)。 | 关闭 |
| Show Volume Overlay | 当音量键改变 Curve 的音量时，在菜单栏的声音图标下方显示音量。 | 打开 |
| Global Menu Shortcut | 设置可从任何位置打开 Curve 菜单的组合键。请参阅[键盘快捷键](keyboard-shortcuts.md)。 | 关闭 |

### MIDI

| 项目 | 功能 | 默认值 |
|---|---|---|
| Program Change Selects Preset | 来自控制器的程序变更会载入预设。请参阅 [MIDI 控制](midi-control.md)。 | 关闭 |
| Next Preset Control, Previous Preset Control | 控制器上用于依次切换预设的按钮。 | |
| Clear Preset Controls | 移除这两个按钮分配。 | |
| MIDI Mappings for Current Preset... | 显示当前载入预设的 MIDI 映射以及每个映射的范围。 | |
