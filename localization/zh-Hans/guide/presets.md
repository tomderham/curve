# 预设

预设会存储整个图：其中的插件及其设置、连接、音频通道路由和 MIDI 映射。切换预设可以更改相同插件的设置、换用不同的插件，或更改通道路由。

## 存储预设

1. 从 Curve 菜单中选择 Save As Preset...。
2. 输入名称并点按 Save。

更改不会自动存储。只要想保留更改，请使用 Save As Preset...。

## 更改现有预设

1. 在 Curve 菜单中选择预设以将其载入。
2. 进行更改。
3. 选择 Save As Preset...，选择现有名称，然后确认要替换它。

## 切换预设

你的预设按字母顺序列在 Curve 菜单中，当前预设带有勾号。选择一个预设即可立即切换。Curve 不会先询问，因此请在切换前存储想保留的更改。

你也可以[用键盘](keyboard-shortcuts.md)或[通过 MIDI 控制器](midi-control.md)切换预设。要直接载入预设文件，请将其拖到编辑器窗口上。

## 开始新预设

要从空白的图重新开始，请点按编辑器窗口左上角的菜单图标，然后选择 New Preset。除 Audio Input、Interface Loopback (In) 和 Audio Output 外，所有节点都会被移除。这些节点没有连接，因此在连接它们之前不会有声音。

除非图中只有这些节点，否则 Curve 会先询问，因为在插件窗口中更改的设置不会被记录为更改。选择 Save As Preset... 以保留当前设置，或选择 Discard and Start New。

## 场景

如果多个预设有共同的部分，可以把它们设为场景。例如，几个场景可以共用同一套扬声器校正，但使用不同的乐器或信号路径；也可以使用相同的乐器，但扬声器校正不同。场景共享它们的插件和连接，因此只需更改一次，就能更新所有场景。每个场景都像其他预设一样留在 Curve 的菜单中，切换方式也相同。

相互共享的场景在 Curve 的菜单和 Save Preset 窗口中以相同的颜色标记。

切换到另一个场景很快：Curve 只更改该场景自己的部分，不会重新载入插件。如果载入后更改了共享的设置，或者缺少某个插件，场景会完整载入，这项更改会丢失，与切换预设时一样。

每个场景各自保留的内容：

- 它的速度。请参阅[速度和走带](editor.md)。
- 每个节点是旁通还是静音。旁通的节点会让输入原样通过。静音的节点不输出任何内容，因此会切断它所在的路径。请参阅[将节点静音](editor.md)。
- 设为 Vary by Scene 的节点的设置。右键点按节点并选择 Vary by Scene，节点上会显示一个小的叠放卡片标记。
- 随它一起打开的插件窗口（Always Open Plug-in GUI with Preset）及其位置。添加到某个场景的节点不会在其他场景中打开。

其他内容都是共享的：其他节点及其设置、连接、声道路由以及 MIDI 映射。在任何场景中更改共享节点并存储后，所有场景都会获得这项更改。设为 Vary by Scene 的节点仍然共享它的声道和连接。

要创建场景：

1. 载入新场景要基于的预设。
2. 对于在新场景中设置不同的每个插件，右键点按它并选择 Vary by Scene。
3. 为新场景进行更改。要去掉一条路径，请将该路径上的一个节点静音。
4. 选择 Save As Preset...，输入新名称，选择场景选项，然后点按 Save。

存储之前，Save Preset 窗口会列出这次存储会更新哪些其他场景，以及在这些场景中设置会改变的共享节点。如果某项更改只用于此场景，请取消，右键点按该节点并选择 Vary by Scene，然后再次存储。这样每个场景都会保留该节点各自的设置。它仍然是场景，各场景仍然共享其他所有内容。

要更改场景，请载入它，进行更改，然后以相同名称存储。覆盖与它共享的另一个场景会替换该场景，并且它仍然是场景。你添加的节点也会以旁通状态出现在其他场景中，因此在那里打开它之前，声音保持不变。旁通的节点仍会让输入通过，因此要让新路径在其他场景中保持静音，请在那里将它的一个节点静音。

要让某个场景不再与其他场景共享，请在 Save Preset 窗口中右键点按它，然后选择 Convert to Standalone Preset。它会保留当前的设置。

## 重命名或删除预设

在 Save Preset 窗口中，右键点按预设可将其重命名、移到废纸篓或在访达中显示。

预设是位于 `~/Library/Application Support/Curve/Presets/` 中的 `.filtergraph` 文件，因此你也可以在访达中管理它们。
