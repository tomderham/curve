# Curve Help

本帮助由机器翻译。欢迎在 [GitHub](https://github.com/tomderham/curve/issues) 上提出更正。

Curve 是一款免费、轻量的 macOS 音频插件宿主。它运行在菜单栏中，让一条由 Audio Unit 和 VST3 插件组成的链在后台持续运行，因此你可以为 Mac 的音频应用 EQ、耳机处理和其他效果，并即时切换不同的设置。

- [预设](presets.md)：存储、载入、切换、重命名和删除预设。
- [编辑器](editor.md)：添加节点、连接节点、旁通节点并打开插件窗口。
