# ऑडियो सेटिंग्स और डिवाइस

अपने ऑडियो और MIDI डिवाइस चुनने के लिए Settings > Audio Settings चुनें।

## इंटरफ़ेस और चैनल चुनें

एक आउटपुट इंटरफ़ेस चुनें, और यदि आपका प्रीसेट इनपुट इंटरफ़ेस का उपयोग करता है तो वह भी चुनें। फिर अपने इच्छित चैनल चालू करें। वे Audio Input और Audio Output नोड पर ग्रे पिन के रूप में दिखाई देते हैं।

यदि आप Curve के [Interface Loopback (In) नोड](loopback.md) का उपयोग कर रहे हैं, तो आपको इनपुट इंटरफ़ेस की ज़रूरत नहीं है।

Curve हर आउटपुट इंटरफ़ेस का सैंपल रेट, बफ़र साइज़ और चालू किए गए आउटपुट चैनल याद रखता है, और उस इंटरफ़ेस पर वापस आने पर उन्हें बहाल कर देता है।

## macOS के आउटपुट का पालन करें

macOS को Curve का आउटपुट चुनने देने के लिए **Use output interface selected in macOS** चालू करें। जब आप सिस्टम सेटिंग्स, कंट्रोल सेंटर या मेनू बार में कोई आउटपुट चुनते हैं, तो Curve लगभग एक सेकंड में अपनी प्रोसेसिंग वहाँ ले जाता है। यदि वह इंटरफ़ेस डिस्कनेक्ट हो जाता है, तो Curve उस आउटपुट पर चला जाता है जिसका macOS आगे उपयोग करता है। यह चालू रहने पर Curve का Output मेनू ग्रे हो जाता है।

आपके प्रीसेट के उन आउटपुट से कनेक्शन बने रहते हैं जो नए इंटरफ़ेस में नहीं हैं, लेकिन वे तब तक साइलेंट रहते हैं जब तक आप ऐसे इंटरफ़ेस पर वापस नहीं आते जिसमें वे आउटपुट हों। किसी एक इंटरफ़ेस के लिए बनाया गया करेक्शन, जैसे किसी खास हेडफ़ोन का EQ, उस हर आउटपुट पर लागू होता है जिस पर macOS स्विच करता है।

यह चालू होने पर, हर इंटरफ़ेस के लिए एक प्रीसेट चुनने के लिए **Default Presets for each output interface...** चुनें। जब macOS किसी इंटरफ़ेस पर स्विच करता है, तो Curve उसका डिफ़ॉल्ट प्रीसेट लोड करता है। None पर सेट इंटरफ़ेस लोड किए गए प्रीसेट को ही रखते हैं। Curve शुरू होने पर पिछली बार इस्तेमाल किए गए प्रीसेट के बजाय macOS जिस इंटरफ़ेस का उपयोग कर रहा है उसका डिफ़ॉल्ट प्रीसेट लोड करने के लिए **Also load at launch** चालू करें। यदि कोई डिफ़ॉल्ट प्रीसेट नहीं मिलता, तो Curve मौजूदा प्रीसेट रखता है और एडिटर के स्टेटस बार में यह बताता है।

## macOS को Curve के इंटरफ़ेस पर रखें

**Force macOS system output to this interface** डिफ़ॉल्ट रूप से चालू है। यह macOS के सिस्टम आउटपुट को Curve के आउटपुट इंटरफ़ेस पर बनाए रखता है, ताकि [Interface Loopback (In) नोड](loopback.md) को पूरा सिस्टम ऑडियो मिले। यदि आप सिस्टम आउटपुट खुद चुनना चाहते हैं, तो इसे बंद करें। Use output interface selected in macOS चालू रहने पर यह ग्रे रहता है, क्योंकि तब macOS का आउटपुट हमेशा Curve का ही आउटपुट होता है।

## सैंपल रेट और बफ़र साइज़

सैंपल रेट और बफ़र साइज़ यहाँ चुनें। छोटे बफ़र से लेटेंसी कम होती है, लेकिन आपके Mac पर लोड बढ़ता है और ऑडियो में रुकावट आ सकती है।

**Always enforce sample rate** डिफ़ॉल्ट रूप से बंद है। बंद होने पर, यदि ऑडियो इंटरफ़ेस या कोई अन्य ऐप हार्डवेयर का सैंपल रेट बदलता है तो Curve उसके अनुसार ढल जाता है। चालू होने पर, Curve रेट को वापस आपके चुने हुए मान पर ले आता है।

## MIDI डिवाइस

जिन MIDI इनपुट और आउटपुट का उपयोग करना है, उन्हें चालू करें। उन्हें प्लग-इन से कनेक्ट करने के लिए MIDI Input या MIDI Output नोड का उपयोग करें। [MIDI कंट्रोल](midi-control.md) के लिए उपयोग किए जाने वाले कंट्रोलर को यहाँ चालू करना ज़रूरी है।

## जब डिवाइस बदलते हैं

Curve डिवाइस से जुड़े आम बदलावों को अपने आप संभालता है:

- यह आपके चुने हुए इंटरफ़ेस पर ही रहता है, जब तक Use output interface selected in macOS चालू न हो। यदि वह इंटरफ़ेस डिस्कनेक्ट हो जाता है, तो Curve आपके Mac के स्पीकर जैसे किसी अन्य आउटपुट पर जाने के बजाय साइलेंट हो जाता है।
- इंटरफ़ेस वापस आने पर यह फिर से कनेक्ट होकर ऑडियो बहाल करता है।
- आपके Mac के स्लीप से जागने के बाद यह ऑडियो फिर से शुरू करता है।

## AirPods और ऑटोमैटिक स्विचिंग

जब तक Curve ने कोई ऑडियो इंटरफ़ेस खोल रखा है, macOS शायद AirPods को अपने आप स्विच न करे। इसकी अनुमति देने के लिए Settings > Preferences... चुनें और Release audio interface when idle चालू करें।

इसके बाद Curve 5 सेकंड की खामोशी के बाद इंटरफ़ेस छोड़ देता है, और जब कोई अन्य ऐप उसका उपयोग शुरू करता है तो उसे फिर से खोल लेता है। ऐसा तभी होता है जब Curve भरोसेमंद तरीके से फिर से जाग सके, इसलिए इन स्थितियों में इंटरफ़ेस नहीं छोड़ा जाता:

- आपका इनपुट किसी अलग डिवाइस पर फ़िज़िकल माइक्रोफ़ोन या लाइन इनपुट है। BlackHole जैसे वर्चुअल डिवाइस में कोई समस्या नहीं है। यदि आपके प्रीसेट में Audio Input नोड कनेक्ट है, तो आउटपुट इंटरफ़ेस के इनपुट पर भी यही लागू होता है।
- कोई अन्य ऐप उस डिवाइस का उपयोग कर रहा है।
- Curve व्यस्त है, जैसे रिकॉर्डिंग कर रहा है।
