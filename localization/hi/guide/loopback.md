# लूपबैक और सिस्टम ऑडियो

लूपबैक से आप macOS के ऑडियो को आपके हेडफ़ोन या स्पीकर तक पहुँचने से पहले Curve से गुज़ार सकते हैं। इसी तरह आप अपने Mac पर चलने वाली हर चीज़ पर EQ लगाते हैं।

## Curve के Interface Loopback नोड का उपयोग करें

किसी अतिरिक्त सॉफ़्टवेयर या ड्राइवर की ज़रूरत नहीं है।

1. [Audio Settings](audio-settings.md) में वह आउटपुट इंटरफ़ेस चुनें जिससे आप ऑडियो सुनना चाहते हैं।
2. अपने प्रीसेट में, Audio Input के बजाय Interface Loopback (In) नोड को इनपुट के रूप में उपयोग करें।
3. इसे अपने प्लग-इन से होते हुए Audio Output नोड से कनेक्ट करें।

यह नोड बिट-परफ़ेक्ट ऑडियो प्राप्त करता है जो अन्यथा सीधे आउटपुट इंटरफ़ेस पर जाता। यदि यह मौजूद नहीं है, तो एडिटर के राइट-क्लिक मेनू में Audio I/O से इसे जोड़ें।

## पूरा सिस्टम ऑडियो Curve को भेजें

Settings मेनू में **Force macOS System Audio to loopback** डिफ़ॉल्ट रूप से चालू है। यह macOS के सिस्टम आउटपुट को Curve में चुने गए इंटरफ़ेस पर बनाए रखता है। यदि आप सिस्टम आउटपुट खुद चुनना चाहते हैं, तो इसे बंद करें।

## अपने ऑडियो इंटरफ़ेस के लूपबैक का उपयोग करें

वैकल्पिक रूप से, यदि आपके इंटरफ़ेस में हार्डवेयर लूपबैक है, तो यह एक अच्छा विकल्प हो सकता है क्योंकि इससे लेटेंसी कम से कम हो सकती है। उदाहरण के लिए, RME TotalMix के साथ:

1. TotalMix के Loopback फ़ंक्शन से आउटपुट चैनल की एक जोड़ी को इनपुट चैनल की एक खाली जोड़ी पर भेजें।
2. Curve में उन इनपुट चैनल को चुनें और Audio Input नोड का उपयोग करें।
3. कुछ सॉफ़्टवेयर प्लेबैक चैनल को Curve के आउटपुट के रूप में चुनें।
4. TotalMix में उन प्लेबैक चैनल को अपने हार्डवेयर आउटपुट पर असाइन करें।

इस सेटअप में Interface Loopback (In) नोड का उपयोग न करें।

## महत्वपूर्ण: अनुपयोगी लूपबैक पिन

यदि Interface Loopback (In) नोड कनेक्ट है, तो उन चैनल का सीधा ऑडियो आउटपुट डिवाइस तक नहीं पहुँचता। यदि यह ऐसे प्रीसेट में है जिसमें आप इसका उपयोग नहीं कर रहे, तो इसे हटा दें या इसके पिन अनकनेक्टेड छोड़ दें, वरना ऑडियो अचानक म्यूट हो सकता है।

## रीडायरेक्ट कैसे काम करता है

जब नोड के पिन कनेक्ट होते हैं, तो चुने गए आउटपुट इंटरफ़ेस की प्राइमरी स्ट्रीम, Stream 0, के चैनल नोड पर रीडायरेक्ट हो जाते हैं। जिन चैनल को इंटरफ़ेस का ड्राइवर किसी अन्य स्ट्रीम को असाइन करता है, वे प्रभावित नहीं होते।
