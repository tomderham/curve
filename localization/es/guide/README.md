# Curve Help

Esta ayuda se ha traducido automáticamente. Las correcciones son bienvenidas [en GitHub](https://github.com/tomderham/curve/issues).

Curve es un host de plug-ins de audio gratuito y ligero para macOS. Se ejecuta en la barra de menús y mantiene activa en segundo plano una cadena de plug-ins Audio Unit y VST3, para que puedas aplicar EQ, procesamiento para auriculares y otros efectos al audio de tu Mac, y cambiar de configuración al instante.

## Primeros pasos

- [Primeros pasos](getting-started.md): instala Curve, busca plug-ins y crea tu primer preset.
- [Presets](presets.md): guarda, carga, cambia, renombra y elimina presets.
- [El editor](editor.md): añade nodos, conéctalos, omítelos y abre las ventanas de los plug-ins.
