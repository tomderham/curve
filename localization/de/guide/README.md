# Curve Help

Diese Hilfe wurde maschinell übersetzt. Korrekturen sind [auf GitHub](https://github.com/tomderham/curve/issues) willkommen.

Curve ist ein kostenloser, schlanker Audio-Plug-in-Host für macOS. Er läuft in der Menüleiste und hält im Hintergrund eine Kette aus Audio-Unit- und VST3-Plug-ins aktiv. So kannst du EQ, Kopfhörerbearbeitung und andere Effekte auf den gesamten Ton deines Mac anwenden und sofort zwischen verschiedenen Setups wechseln.

- [Presets](presets.md): Presets speichern, laden, wechseln, umbenennen und löschen.
- [Der Editor](editor.md): Nodes hinzufügen, verbinden, umgehen und Plug-in-Fenster öffnen.
