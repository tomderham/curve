# Einstellungen im Überblick

Öffne Settings in Curves Menü.

| Eintrag | Funktion | Standard |
|---|---|---|
| Audio Settings | Audio- und MIDI-Geräte auswählen. Siehe [Audioeinstellungen und Geräte](audio-settings.md). | |
| Plug-in Manager | Nach Plug-ins suchen und sie verwalten. Siehe [Erste Schritte](getting-started.md). | |
| Force macOS System Audio to loopback | Hält die Systemausgabe von macOS auf dem in Curve ausgewählten Interface. Siehe [Loopback](loopback.md). | Ein |
| Prevent macOS from automatically sleeping | Verhindert, dass dein Mac in den Ruhezustand wechselt, solange Curve Audio verarbeitet. | Aus |
| Release audio interface when idle | Gibt das Interface nach 5 Sekunden Stille frei, damit AirPods automatisch umschalten können. Siehe [Audioeinstellungen](audio-settings.md). | Aus |
| Check for Updates... | Sucht jetzt nach einer neuen Version. | |
| Auto-Check for App Updates | Sucht automatisch nach neuen Versionen. | Ein |
| Open at Login | Startet Curve bei der Anmeldung. | |
| Show in Dock | Zeigt Curve im Dock und im Befehl-Tab-Umschalter an. | Aus |
| Global Menu Shortcut | Legt eine Tastenkombination fest, die Curves Menü von überall öffnet. Siehe [Tastaturkurzbefehle](keyboard-shortcuts.md). | Aus |
| MIDI Control | Richtet den Preset-Wechsel über einen Controller ein. Siehe [MIDI-Steuerung](midi-control.md). | |
| Curve Help | Öffnet diese Anleitung. | |
| About... | Zeigt Version und Lizenzangaben an. | |
| Quit | Beendet Curve und stoppt die Audioverarbeitung. | |
