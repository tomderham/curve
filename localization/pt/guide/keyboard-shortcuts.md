# Atalhos de teclado

## Abrir o menu do Curve de qualquer lugar

O atalho global abre o menu do Curve mesmo quando outro app está em primeiro plano. Ele fica desativado até você configurá-lo.

1. Selecione Settings > Global Menu Shortcut.
2. Clique em Record Shortcut e pressione uma combinação de teclas que inclua Command, Option ou Control. Pressione Esc para cancelar.
3. Clique em Save.

Clique em Reset to Default para usar ⌥⇧C, ou em Disable para desligar o atalho.

## Ajustar o volume do Curve com as teclas de volume

Algumas interfaces de áudio não têm um controle de volume que o macOS possa usar, então as teclas de volume do teclado não fazem nada. O Curve pode usar as teclas para ajustar o próprio volume de saída.

1. Selecione Settings > Volume Keys > When macOS Can't Control the Interface's Volume.
2. Quando o macOS pedir, dê acesso ao Curve em Ajustes do Sistema > Privacidade e Segurança > Acessibilidade. O Curve precisa disso para captar as teclas.

O Curve então mostra o próprio indicador de volume abaixo do ícone de Som na barra de menus, como o macOS faz.

- As teclas de volume passam por 16 níveis, como no macOS. Mantenha Shift e Option pressionadas com uma tecla de volume para passos mais finos.
- A tecla de silenciar desliga e liga a saída do Curve.

O Curve só usa as teclas enquanto a saída do macOS for a interface de saída do Curve e o macOS não puder ajustar o volume dos canais pelos quais o Curve toca. Isso inclui interfaces sem nenhum controle de volume e interfaces cujo controle de volume no macOS cobre só alguns dos seus canais, não os que o Curve usa. Caso contrário, as teclas funcionam normalmente no macOS. Para que as teclas sempre ajustem o volume do Curve, selecione Always.

O volume do Curve vale para tudo o que o Curve envia à saída, depois dos seus plug-ins, e só enquanto as teclas o ajustam. O Curve se lembra dele quando você o encerra. No volume máximo, o áudio não é alterado.

Para ocultar o indicador, desative Show Volume Overlay no mesmo menu.

## Alternar presets pelo teclado

Com o menu do Curve aberto, pressione uma tecla para selecionar um preset. A tecla aparece ao lado de cada preset.

| Presets | Teclas |
|---|---|
| 1 a 10 | 1 a 0 |
| 11 a 20 | Option com 1 a 0 |
| 21 a 30 | Shift com 1 a 0 |

Por exemplo, pressione o atalho global e depois 2 para passar ao segundo preset a partir de qualquer app.

## No editor durante o MIDI Learn

| Tecla | Ação |
|---|---|
| Esc | Concluir o MIDI Learn |
| Delete | Remover o mapeamento do controle selecionado |
