# Atalhos de teclado

## Abrir o menu do Curve de qualquer lugar

O atalho global abre o menu do Curve mesmo quando outro app está em primeiro plano. Ele fica desativado até você configurá-lo.

1. Selecione Settings > Global Menu Shortcut.
2. Clique em Record Shortcut e pressione uma combinação de teclas que inclua Command, Option ou Control. Pressione Esc para cancelar.
3. Clique em Save.

Clique em Reset to Default para usar ⌥⇧C, ou em Disable para desligar o atalho.

## Alternar presets pelo teclado

Com o menu do Curve aberto, pressione uma tecla para selecionar um preset. A tecla aparece ao lado de cada preset.

| Presets | Teclas |
|---|---|
| 1 a 10 | 1 a 0 |
| 11 a 20 | Option com 1 a 0 |
| 21 a 30 | Shift com 1 a 0 |

Por exemplo, pressione o atalho global e depois 2 para passar ao segundo preset a partir de qualquer app.

## No editor durante o MIDI Learn

| Tecla | Ação |
|---|---|
| Esc | Concluir o MIDI Learn |
| Delete | Remover o mapeamento do controle selecionado |
