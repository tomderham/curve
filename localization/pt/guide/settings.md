# Referência de ajustes

Abra Settings no menu do Curve.

| Item | Função | Padrão |
|---|---|---|
| Audio Settings | Escolhe dispositivos de áudio e MIDI. Consulte [Ajustes de áudio e dispositivos](audio-settings.md). | |
| Plug-in Manager | Procura e gerencia plug-ins. Consulte [Primeiros passos](getting-started.md). | |
| Force macOS System Audio to loopback | Mantém a saída do sistema do macOS na interface selecionada no Curve. Consulte [Loopback](loopback.md). | Ativado |
| Prevent macOS from automatically sleeping | Impede que o Mac entre em repouso enquanto o áudio do Curve estiver em execução. | Desativado |
| Release audio interface when idle | Libera a interface após 5 segundos de silêncio, o que permite a troca automática dos AirPods. Consulte [Ajustes de áudio](audio-settings.md). | Desativado |
| Check for Updates... | Verifica agora se há uma nova versão. | |
| Auto-Check for App Updates | Verifica automaticamente se há novas versões. | Ativado |
| Open at Login | Inicia o Curve quando você faz login. | |
| Show in Dock | Mostra o Curve no Dock e no alternador Command-Tab. | Desativado |
| Global Menu Shortcut | Define uma combinação de teclas que abre o menu do Curve de qualquer lugar. Consulte [Atalhos de teclado](keyboard-shortcuts.md). | Desativado |
| MIDI Control | Configura a alternância de presets a partir de um controlador. Consulte [Controle MIDI](midi-control.md). | |
| Curve Help | Abre este guia. | |
| About... | Mostra a versão e os detalhes da licença. | |
| Quit | Encerra o Curve e interrompe o processamento de áudio. | |
