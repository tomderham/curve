# Curve Help

Esta ajuda foi traduzida automaticamente. Correções são bem-vindas [no GitHub](https://github.com/tomderham/curve/issues).

O Curve é um host de plug-ins de áudio gratuito e leve para macOS. Ele fica na barra de menus e mantém uma cadeia de plug-ins Audio Unit e VST3 em execução em segundo plano, para que você possa aplicar EQ, processamento para fones de ouvido e outros efeitos ao áudio do seu Mac e alternar entre configurações instantaneamente.
