# Curve Help

Curve is a free, lightweight audio plug-in host for macOS. It runs in the menu bar and keeps a chain of Audio Unit and VST3 plug-ins running in the background, so you can apply EQ, headphone processing and other effects to your Mac's audio, and switch between setups instantly.

## Get started

- [Getting started](getting-started.md): install Curve, scan for plug-ins and build your first preset.
- [Presets](presets.md): save, load, switch, rename and delete presets.
- [The editor](editor.md): add nodes, connect them, bypass them and open plug-in windows.

## Audio

- [Audio settings and devices](audio-settings.md): choose interfaces, channels, sample rate and buffer size, and how Curve handles device changes.
- [Loopback and system audio](loopback.md): process audio from macOS or other apps through Curve.
